# Site presentation notes

This repository is the canonical home of the Harness Assessment. The book's companion site, le.correax.com, presents the results: a method page at `/harness-assessment/`, one results page per tool, dated and versioned, linked from the method page and from the Chapter 17 page.

Publication order matters: the site presents only results that exist in this repository. The method page on the site publishes with the first completed run, not before, so the site never advertises results that do not exist.

Each completed tool run is also announced on the site as a dated field update. Results pages carry a "tested on" date and a "retest due" note (major version change or six months, whichever comes first).
