# Workstands and Tools

The shop has six workstands and a shared tool wall. Tools stay in the
shop. Riders sign tools out at the bench and return them before leaving.

## Workstands

Raise the bike so the wheels clear the floor. Clamp the seat post, not
the frame tube. Before starting any repair, review the precautions in
[Doc 4, Safety](doc-04.md#safety).

## Tool Care

Wipe tools down at the end of each shift. Report bent or broken tools to
the shift lead so replacements can be ordered through [Doc 8](doc-08.md).
Loaner tools for off-site events are listed in [Doc 13](doc-13.md),
which also covers the sign-out sheet.
