# Closing Checklist and Records

The shift lead closes the shop. Closing takes about twenty minutes when
the benches were kept tidy through the session.

## Closing Steps

1. Return every tool to the tool wall, following [Doc 3, Tool Care](doc-03.md#tool-care).
2. Sweep the floor and empty the small trash bin.
3. Count the register and lock the donation box.
4. Note any incident from the session, as described in [Doc 4](doc-04.md).

## Records

Intake tags, incident forms, and the register count go in the gray
binder by date. Keep records for two years. The monthly inventory count
from [Doc 8](doc-08.md) is filed at the back of the same binder.
