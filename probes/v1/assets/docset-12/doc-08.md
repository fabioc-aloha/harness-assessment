# Parts and Inventory

The parts wall holds the stock we use every week: tubes, cables, pads,
chains, and common bolts. The inventory count happens on the last
Saturday of each month.

## Stock Levels

Keep at least ten of each tube size on hand. When a bin drops below its
marked line, add the part to the order list. Order spending follows the
budget rules in [Doc 10](doc-10.md).

## Receiving Orders

Check each delivery against the order list before shelving. Note damaged
items the same day. The month-end count is filed with the records
described in [Doc 12](doc-12.md).
