# Events and Classes

The workshop runs a basic maintenance class on the first Tuesday of each
month and a fix-a-flat night on the third Thursday.

## Class Nights

Classes cap at twelve riders. The instructor arrives thirty minutes
early to set up stands, using the layout in [Doc 3](doc-03.md).
Shift swaps follow the schedule rules in [Doc 9](doc-08.md).

## Open Events

Off-site repair days need at least four volunteers. Sign-up sheets for
events are posted with the monthly roster described in
[Doc 9](doc-09.md).
